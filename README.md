# Caram Helados — Landing Page (proyecto completo)

Construye una landing page de una sola página (single-page) en español para "Caram Helados", una heladería artesanal en Puerto Padre, Las Tunas, Cuba. Debe verse pulida, cálida y apetitosa — moderna pero accesible. Totalmente responsive (móvil, tablet, escritorio), con navegación por anclas y scroll suave.

## Paleta y estilo
- Fondo principal: azul marino oscuro (aprox. #14264D), con degradado sutil tipo cielo nocturno y destellos en el héroe.
- Acento: naranja vibrante (aprox. #F5821F) para títulos destacados, precios e íconos.
- Botones de WhatsApp: verde WhatsApp (#25D366), forma píldora, con ícono de WhatsApp.
- Tarjetas de productos: fondo crema/beige claro (aprox. #F3E6D1) sobre el azul marino, esquinas redondeadas, sombra suave.
- Tipografía sugerida: Poppins, Nunito o Quicksand para el cuerpo (redondeada, amigable); el logotipo "Caram" en fuente script/cursiva (tipo Pacifico) dentro de una insignia ovalada azul marino con borde dorado y "HELADOS" en mayúsculas pequeñas debajo.
- Iconos de línea simples y circulares (hoja, copo de nieve, círculo tachado, camión, corazón, personas, fiesta, mochila, calendario, gorro de fiesta, trofeo, regalo, portapapeles).
- Animaciones sutiles: fade/slide-in al hacer scroll, hover en tarjetas y botones.

## Requisitos técnicos
- React + Tailwind, componentes limpios por sección.
- Todos los botones de WhatsApp y el número de teléfono enlazan a wa.me/5355260778 (nueva pestaña).
- "Nosotros" ancla a la sección de confianza/testimonios; "Contacto" ancla a la sección final/footer.
- Diseño mobile-first, totalmente responsive.
- Usa fotografía de stock apetitosa y de alta calidad para helados/tinas/escena de cumpleaños, y avatares para testimonios.
